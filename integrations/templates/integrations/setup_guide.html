Google Search Console koppelen

  1. Maak of kies een Google Cloud-project. Open de Google Cloud Console met het account dat de OAuth-client gaat beheren.
  2. Activeer de Google Search Console API. Zoek deze op in de API Library en kies Enable.
  3. Configureer Google Auth Platform. Vul Branding, Audience en contactgegevens in. Bij een externe app in testmodus voeg je de Google-accounts die gaan koppelen toe als testgebruikers. Voor breder gebruik kan Google publicatie en verificatie verlangen. In testmodus kan een koppeling na zeven dagen verlopen.
  4. Voeg alleen leestoegang toe. Gebruik onder Data Access de scope https://www.googleapis.com/auth/webmasters.readonly.
  5. Maak een OAuth-client. Kies onder Clients het type Web application. Voeg onder Authorized redirect URIs exact toe:
    {{ redirect_uri }}
  6. Sla de clientgegevens hier op. Vul de client-ID en het client secret in op de instellingenpagina. Een herstart van de applicatie is niet nodig.
  7. Koppel een project en controleer de toegang. Ga naar Projecten, open een project en kies Koppelingen → Verbinden met Google. Geef toestemming en kies een property waarvoor het Google-account toegang heeft. Daarna kun je een import starten, dagelijkse imports beheren en URL’s inspecteren.

Als het koppelen niet lukt

  • redirect_uri_mismatch: vergelijk de redirect-URI exact, inclusief https en de afsluitende slash.
  • Toegang geweigerd: controleer testgebruikers, toestemming en toegang tot de property in Search Console.
  • Geen properties: gebruik het Google-account waaraan de website in Search Console is gekoppeld.
  • API niet actief: controleer of de Search Console API aanstaat in hetzelfde Cloud-project als de client.

Officiële uitleg: Google OAuth voor webapplicaties en Search Console-autorisatie.
